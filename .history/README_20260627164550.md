# RISC-V Single Cycle CPU

A single-cycle RISC-V processor implemented in Verilog, synthesized on an Intel FPGA (Cyclone V) using Quartus Prime.

## Project Structure

```
CPU_RICSV/
├── rtl/                  # Verilog source files
│   ├── processor.v       # Top-level module
│   ├── data_path.v       # Datapath
│   ├── controller.v      # Control unit
│   ├── IFU.v             # Instruction Fetch Unit
│   ├── INSTR_MEM.v       # Instruction Memory
│   ├── IMM_GEN.v         # Immediate Generator
│   ├── alu.v             # Arithmetic Logic Unit
│   ├── branch_comp.v     # Branch Comparator
│   ├── data_mem.v        # Data Memory
│   ├── reg_file.v        # Register File
│   ├── mux.v             # 2-to-1 Multiplexer
│   └── mux3.v            # 3-to-1 Multiplexer
├── test_bench/           # Testbenches
├── simulation/           # Simulation output files
├── waveform/             # Waveform captures
├── output_files/         # Quartus output (bitstream, reports)
├── Image/                # System diagrams
└── README.md
```

## Supported Instructions

| Type | Instructions |
|------|-------------|
| R-type | `ADD`, `SUB`, `AND`, `OR`, `XOR`, `SLT` |
| I-type | `ADDI`, `LB,LW`, `JALR` |
| S-type | `SW` |
| B-type | `BEQ`, `BNE`, `BLT`, `BGE` |
| J-type | `JAL` |

---

## Modules

| Module | Description |
|--------|-------------|
| `processor.v` | Top-level: connects datapath and controller |
| `data_path.v` | Datapath: PC, ALU, registers, memory |
| `controller.v` | Control unit: generates control signals |
| `IFU.v` | Instruction Fetch Unit: PC update logic |
| `INSTR_MEM.v` | Instruction memory (ROM) |
| `IMM_GEN.v` | Immediate value sign-extension |
| `alu.v` | ALU: arithmetic and logic operations |
| `branch_comp.v` | Branch condition comparator |
| `data_mem.v` | Data memory (RAM) |
| `reg_file.v` | 32 x 32-bit register file |

---

## Tools

- **HDL**: Verilog
- **Synthesis**: Intel Quartus Prime 25.1
- **Target FPGA**: Intel Cyclone V
- **Simulation**: ModelSim / QuestaSim

---

## How to Run

1. Open Quartus Prime and load `CPU_RICS_V.qpf`
2. Compile the project: **Processing → Start Compilation**
3. For simulation, open ModelSim and run the testbench in `test_bench/`
